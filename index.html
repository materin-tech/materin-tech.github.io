静态资源托管Static asset hosting

本站根目录即资源根目录，可被任意项目直接引用。

The repository root is the asset root — reference it directly from any project.

基础地址Base URL

https://materin-tech.github.io/

任意文件放进仓库根目录（或子目录）即可通过同路径访问，CDN 由 GitHub Pages 提供。

Any file committed to the repository root (or a subdirectory) is served at the same path; GitHub Pages provides the CDN.

引用示例Usage

<img src="https://materin-tech.github.io/assets/img/favicon.svg">
<script src="https://materin-tech.github.io/assets/js/main.js"></script>
<link rel="stylesheet"
      href="https://materin-tech.github.io/assets/css/style.css">
缓存提示：Pages 默认缓存约 10 分钟。需要长期强缓存时，把发布文件名带上内容哈希（如 app.3f9a1c.css）。 Caching: Pages caches for roughly 10 minutes. For long-lived caching, hash your asset filenames (e.g. app.3f9a1c.css).

关于 Materin TechAbout Materin Tech

Materin Tech 是一个以「静态优先、仓库自治」为组织方式的技术项目集合。每个项目在自己的仓库里独立演进、互不耦合；组织站点统一承担门面、静态资源分发与项目介绍页的职责。

Materin Tech is a collection of technical projects organized around two principles: static-first and repository autonomy. Each project evolves independently in its own repository; the organization site serves as the single facade, the asset host and the home of project documentation.

  • 一个目录一个仓库，互不耦合One directory, one repository, no coupling
  • 无构建步骤：推送到 main 即发布No build step: pushing to main publishes
  • 介绍页与源码分离，避免路径冲突Docs decoupled from source to avoid path collisions
