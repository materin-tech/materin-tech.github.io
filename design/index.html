Materin UI v0.1

一套 UI，三个插件 —— 颜色、形状、间距都从同一个令牌文件里取。

One UI across three plugins — colour, shape and spacing all come from a single token file.

令牌文件（本站托管）Token file (hosted here) 内容索引Content index

三条原则

一、跟随宿主

颜色、字体、圆角优先取 Obsidian 主题变量（--background-primary、--interactive-accent、--radius-s …）。Materin 只定义「取不到时」的回落值 —— 用户换主题，插件跟着变，代码不用动。

二、一套变量

所有界面只引用 --materin-*，不再出现散落的色值。要改风格，改一个文件。

三、形状与间距固定

圆角统一 --materin-radius（回落 --radius-s）；间距走 4px 基数：4 / 8 / 12 / 16 / 24。跨插件观感一致靠这两条，而不是靠各自调数值。

插件

不做运行时远程 @import：Obsidian 插件打包为单文件，且应当离线可用 —— 令牌随插件一起发布。

Three principles

1 · Follow the host

Colours, fonts and radii prefer Obsidian theme variables (--background-primary, --interactive-accent, --radius-s, …). Materin only defines the fallback used when they are absent — users switch themes and the plugins follow, with no code change.

2 · One set of variables

Every surface references --materin-* only; no loose colour values. Changing the look means changing one file.

3 · Fixed shape and spacing

One radius, --materin-radius (falling back to --radius-s), and one spacing scale on a 4px base: 4 / 8 / 12 / 16 / 24. Consistency across plugins comes from these two rules, not from each plugin tuning its own numbers.

Plugins

Copy the :root block from the token file into the top of a plugin's styles.css; from then on, new styles reference --materin-* only.

No runtime remote @import: Obsidian plugins ship as a single file and must work offline — the tokens travel with the plugin.
