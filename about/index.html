我们是谁

Materin Tech 是一个以「静态优先、仓库自治」为组织方式的技术项目集合。每个项目在自己的仓库里独立演进，不互相耦合；组织站点统一承担门面、静态资源分发与项目介绍页的职责。

设立初衷

  • 项目介绍散落在各个仓库的 README 里，缺少稳定、可分享的统一入口；
  • 图标、样式、示例文件等静态资源在各项目之间反复复制；
  • 需要长期稳定的域名来承载项目介绍、文档与下载指引。

结构约定

约定说明
一个目录一个仓库一个项目一个独立仓库，目录与仓库同名，互不耦合
静态优先站点纯静态、零构建、零依赖，推送到 main 即发布
组织站点即资源根materin-tech.github.io 仓库的根目录就是域名根目录

公开优先免费计划下 GitHub Pages 仅支持 public 仓库
双语介绍与说明同时提供中文与英文，页面右上角一键切换

Who we are

Materin Tech is a collection of technical projects organized around two principles: static-first and repository autonomy. Every project evolves independently in its own repository with no cross-coupling, while the organization site serves as the single facade, the static asset host and the home of project documentation.

Why it exists

  • Project descriptions were scattered across individual repository READMEs, with no stable, shareable entry point;
  • Static assets (icons, styles, sample files) were copied between projects over and over;
  • A long-lived stable domain was needed to host project introductions, docs and download pointers.

Conventions

ConventionRationale
One directory, one repositoryEach project gets its own repository named after its directory, with no cross-coupling
Static-firstThe site is pure static, build-free and dependency-free — pushing to main publishes it
Org site is the asset rootThe root of materin-tech.github.io is the root of the domain
Docs decoupled from sourceIntro pages live under /projects/<repo>/ to avoid colliding with future project-level Pages (/<repo>/)
Public-firstOn the Free plan, GitHub Pages only supports public repositories
BilingualIntroductions ship in Chinese and English; toggle in the top-right corner
