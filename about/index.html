Materin 是什么

Materin 是这个站点的名字，取自「格物」—— 把一件事追到底。《礼记·大学》讲「致知在格物」：先弄清楚，才有真知。

换到今天的话：面对新东西不急着表态，先弄清它是什么、能做什么、边界在哪、说法和事实差多少，再写成不必懂行也能读懂的说明。

内容与代码由 GitHub 组织 materin-tech 承载；所有内容先在这里讲清楚，出处放在最后。

现在发布的内容

目前站上发布的是三个 Obsidian 插件（Materin Office / View / Ctx），每个都有一页站内说明。新的题目在写，写法和它们一样：先弄明白，再写下来。

组织与载体

Materin 是一个以「静态优先、仓库自治」为组织方式的项目集合。每个项目在自己的仓库里独立演进，不互相耦合；本站统一承担门面、资源分发与说明页的职责。

设立初衷

  • 项目介绍散落在各个仓库的 README 里，缺少稳定、可分享的统一入口；
  • 图标、样式、示例文件等静态资源在各项目之间反复复制；
  • 需要长期稳定的域名来承载项目介绍、文档与下载指引。

What Materin is

Materin is the name of this site, taken from 格物 (géwù) — following a thing to the bottom. The Book of Rites has it as "knowledge comes from investigating things": get it straight first, then you know.

In today's terms: when something new appears, don't rush to a verdict. First establish what it is, what it can do, where its edges are, and how far the claims are from the facts — then write it down so that no background is needed.

Content and code live under the GitHub organization materin-tech; everything is explained here first, sources last.

What's published today

The site currently publishes three Obsidian plugins (Materin Office / View / Ctx), each with its own in-site page. New pieces are being written, following the same rule: understand it first, write it down after.

The organization behind it

Materin is a collection of projects organized around two principles: static-first and repository autonomy. Every project evolves independently in its own repository with no cross-coupling, while this site serves as the single facade, the asset host and the home of documentation.

Why it exists

  • Project descriptions were scattered across individual repository READMEs, with no stable, shareable entry point;
  • Static assets (icons, styles, sample files) were copied between projects over and over;
  • A long-lived stable domain was needed to host project introductions, docs and download pointers.
